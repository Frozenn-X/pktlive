Capture health

Represents
OS-level packets received vs dropped, app-queue dropped count, and drop rate % (green <0.5%, orange 0.5–2%, red >2%).
Use it
Monitor capture loss: if drop rate is high, the OS or app is losing packets; reduce load or tune buffer/threads.
Calculation
From _live.json capture_health: os_recv/os_drop from OS stats; drop_rate_pct = 100 × os_drop / (os_recv + os_drop) (or similar).
