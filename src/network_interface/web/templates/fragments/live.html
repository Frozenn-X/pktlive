Represents
Each row is one packet: source IP:port → destination IP:port, protocol (TCP/UDP/ICMP), length (bytes), flags, TTL, and inferred service (e.g. HTTPS from TLS SNI).
Use it
Filter by search (q), protocol, src subnet, port range, or port category. Sort by newest or by size. Check “Anonymize private IPs” to mask 10.x, 172.16–31.x, 192.168.x for sharing. Table refreshes every 0.5 s.
Calculation
Raw packets from the capture; last N kept in memory and written to _live.json (recent_packets). Time = packet timestamp; service from port + optional TLS SNI.
